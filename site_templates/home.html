Fedora Workstation + Niri

Welcome to Kuhl OS

Kuhl OS is a preconfigured Niri desktop for Fedora. It brings together a tiling window manager, a simple launcher, a status bar and useful keyboard shortcuts in one installable setup.

Version 1 base · Release candidate · Free and open-source desktop configuration

Get Kuhl OS

First install Fedora Workstation. Then open Terminal and run the Kuhl OS installer. It adds a Niri session and keeps GNOME available.

Fedora Terminal
curl -fsSL https://raw.githubusercontent.com/TerabyteEXE/Kuhl-OS/main/bootstrap.sh | bash

This runs code downloaded from GitHub. Read the installer before using it. See the installation guide for the manual method, requirements and recovery instructions.

About Kuhl OS

Kuhl OS is not a separate Linux distribution or bootable ISO. It is a set of desktop configurations and a Fedora installer.

The default desktop uses Niri for scrollable tiling, along with Waybar, Fuzzel, Mako and Alacritty. It is intended to be easy to install, understand and modify.

The current release is a base candidate undergoing testing, not a security-audited system.
