Installation

One command. Your desktop.

Start with Fedora Workstation, paste the command, and follow Kuhl's polished terminal setup. No cloning repositories or manually running scripts. The installer downloads Kuhl, checks Niri, previews choices, manages backups and shows real progress.

  1. Open Terminal on Fedora Workstation. Run as your regular user; don't use sudo for the command.
  2. Paste the one command. Choose Day/Dusk and optional features in Kuhl's terminal menu.
  3. Pick Niri at login. Super+Space opens search and Ctrl+Super+K shows your keys.

Upgrading an existing desktop? Select “Replace existing desktop settings (with backups)” in the installer. The option is off by default and requires confirmation.

Experimental project · Fedora x86_64 · GNOME kept as fallback. Review the bootstrap source before running a remote install script.

Good to know

Built like a project you can trust.

Is Kuhl a separate Linux distribution?

No. Kuhl is a curated Fedora Workstation experience, delivered as an installer and configuration project. You keep Fedora's packages, updates and a GNOME session.

Can I use my own wallpaper?

Absolutely. Kuhl starts with solid Day/Dusk backgrounds rather than generated art. Run kuhl wallpaper set ~/Pictures/example.png. Original Kuhl artwork is available but not the default.

Will this replace existing desktop configs?

Not silently. The one-command installer keeps them unless you select “Replace existing desktop settings (with backups)” and confirm by typing REPLACE.

Does Kuhl include AI or telemetry?

Kuhl itself ships no AI feature or telemetry collector. Vicinae is an optional external launcher with its own settings and policies; review those separately if you enable it.
