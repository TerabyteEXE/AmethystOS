AmethystOS / Setup

Install AmethystOS.

Start with a fresh install of Fedora Workstation. you will add AmethystOS as a separate Niri session. Do keep GNOME available if you need it.

Before you start

  • Fedora Workstation install, an internet connection, sudo privileges, and enough storage for the Niri desktop packages. The installer checks that at least 1 GiB is free on / before installing.
  • Use a normal user account. The installer requests sudo only when installing packages. Do not launch it as root.
  • Make a backup. Existing dotfiles are prompted before replacement and are backed up, but you should still keep your own backup of important data just in case.
  • This isn't a new operating-system image(yet). Install Fedora normally first; AmethystOS adds a session rather than replacing your OS.

One-command setup

On Fedora, open Terminal and paste the command below. It fetches the repository's current main branch, so read the bootstrap script first.

Fedora Terminal
curl -fsSL https://raw.githubusercontent.com/TerabyteEXE/AmethystOS/main/bootstrap.sh | bash
Security: This command executes remotely downloaded code. It isn't pinned to a release commit. Review the source, and use the manual method below if you prefer inspecting files first.
1

Check the environment

The installer checks Fedora, permissions, disk space and repository files.

2

Install the desktop

DNF installs Niri, Waybar, Fuzzel, notifications and supporting packages. Optional apps such as Starship don't block setup when unavailable.

3

Configure safely

When existing dotfiles are found, choose whether to replace them after creating a recoverable backup.

4

Finish, reboot, and log in.

The installer validates the Niri configuration before deploying it. Reboot, choose Niri at your login screen and sign back into your new desktop;)

Manual installation

If you want to inspect the project before running any code:

Fedora Terminal
git clone https://github.com/TerabyteEXE/AmethystOS.git
cd AmethystOS
less bootstrap.sh
less install.sh
bash install.sh --dry-run
bash install.sh

Local testing can be run with bash tests/validate.sh. The included native Niri parser runs only where Niri is installed.

After installation

  • At login, select Niri using the session selector (it should look like a gear icon).
  • Press Super + Enter to open the terminal or Super + Space for the launcher.
  • Press Super + Shift + / to display Niri's built-in hotkey overlay.
  • For all configured shortcuts, open the keybinding reference.

Backups and recovery

AmethystOS stores backup state at ~/.local/state/amethystos-base-v1/. If you need your previous desktop settings, use the repository's restore script:

From a local repository checkout
cd AmethystOS
bash uninstall.sh

Run the clone command from the manual installation section first if you installed remotely and no longer have the repository directory. The restore script avoids deleting configs that you've modified since installation. It does not uninstall Fedora packages or remove GNOME.

Having trouble? Start with the troubleshooting guide. Never delete ~/.config/niri without checking backups.
