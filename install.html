Installation

Install AmethystOS

A Fedora Workstation desktop setup, with GNOME preserved for recovery.

On this page

RequirementsInstallChoose appsUpgradeRestore

Requirements

Fedora Workstation 44 or newer, working graphics acceleration, available disk space, and an internet connection. Review the source before installing.

One-command setup

curl -fsSL https://raw.githubusercontent.com/TerabyteEXE/AmethystOS/main/bootstrap.sh | bash

The installer uses Fedora’s official Niri and Noctalia packages. It does not add an external RPM repository.

Choose applications

Navigate the setup checklist with ↑ and ↓. Press Space to select individual apps (including Steam, OBS Studio, LibreOffice, Krita and Chromium) and Enter to continue. Flathub apps require an explicit choice and use an external software source.

Upgrade from an older release

Prefer logging into GNOME before replacing a working Noctalia v4 setup. The new Noctalia v5 configuration is a fresh TOML profile, not a drop-in v4 upgrade. Keep a VM snapshot before replacing your existing config.

bash install.sh --dry-run
bash install.sh

Choose Back up and replace existing configs to proceed with a migration. Read the migration notes.

Uninstall and restore

amethystos-uninstall --dry-run
amethystos-uninstall

This restores your backed-up managed files when unmodified. It does not remove packages or undo Fedora updates.
