# Changelog

## Niri source rebase — beta

- Replaced KyleOS-derived desktop config with selected MIT-licensed `saatvik333/niri-dotfiles` source files.
- Ported source gapless Niri layout, animations, Rofi launcher, terminal colors, Mako notifications and vertical Waybar to Fedora.
- Avoided Arch/AUR scripts, hardcoded monitor IDs, assumed Intel backlights and unlicensed wallpaper submodule.
- Preserved Kuhl's one-command Fedora TUI installer, backup system, Control Center, scaling and Kuhl shortcuts.
- Simplified default palette to Sevens / Day / Dusk, all derived from theme manifest.
- Added clearer source attribution and an explicit AI/security warning.

**Beta:** native Fedora/Niri compositor, portal, settings and bar interaction tests are still required.
