Start with these checks

If something doesn't work, start by checking the Niri configuration and your session logs. If the graphical session is unusable, log out and choose GNOME at the login screen.

Fedora Terminal
niri validate
journalctl --user -b -p warning --no-pager | tail -n 80

DNF says “No match for argument: starship”

This was an early installer error. The current base keeps Starship optional. If you see it stop the installation, make sure you've downloaded the newest repository version. You do not need Starship to run Niri.

Niri doesn't appear at login

Check that Fedora's Niri package is installed and that the installer completed the package stage. Log out completely, reboot, and look for the session selection control in your login manager. AmethystOS does not change the default GNOME session for you.

Black screen or frozen desktop

Use a text console with Ctrl + Alt + F3 if possible, or return to GNOME. Older GPUs and virtual-machine graphics acceleration can affect Wayland sessions. Try Niri on supported hardware and inspect your session logs; do not delete desktop configurations blindly.

Waybar or launcher is missing

Start the component from a terminal to read errors:

Run individually for diagnostic output
waybar
fuzzel

Waybar and Fuzzel need a running Wayland session; they won't work from an ordinary GNOME terminal in the same way as when launched under Niri.

I want my old dotfiles back

Run amethystos-uninstall from any terminal, or bash uninstall.sh from a local repository checkout, to restore files tracked by the installer, as long as they haven't been modified since deployment. Installed packages remain.

App starts and closes immediately

Try launching the same app from Alacritty to read its error messages, then run amethyst-doctor. The system cannot automatically repair missing Flatpak runtimes, external repositories or unsupported graphics drivers. Use gtk-launch DESKTOP-ID to test a desktop entry.

Text spacing or missing icons

AmethystOS installs Cascadia Mono NF and sets readable default terminal sizes. Check the font with fc-match "Cascadia Mono NF", then log out and back into Niri after upgrading. Some applications use their own fonts.

About security

The installer obtains source code from GitHub over HTTPS and executes it. The one-command shortcut follows the current main branch, not a fixed checksum. Inspect bootstrap.sh, install.sh, and the files under scripts/ before installing, especially on a primary machine.

AmethystOS is AI-assisted and not independently security audited. Keep backups and test before deployment. See SECURITY.md for the maintained security notes.
