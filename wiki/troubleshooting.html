First checks

AmethystOS is a Fedora/Niri configuration, not a replacement boot system. If the desktop fails, use GNOME at login or a text console (Ctrl + Alt + F3) for recovery.

amethyst-doctor
niri validate
journalctl --user -b -p warning --no-pager | tail -n 80

The bar or launcher does not appear

Gigi's Rice requires Noctalia Shell v4.7.7, not Fedora 44's new v5 shell. Check the package, runtime and shell log:

rpm -q noctalia-legacy
command -v qs
qs -c noctalia-shell
qs -c noctalia-shell ipc show

Start the shell once only. Gigi's Niri config automatically starts it when you log in.

Installer cannot find Noctalia v4

The legacy package is distributed by third parties, which require your review and consent. Read the installer guide. Do not install Fedora's incompatible noctalia v5 in its place.

Blur, animations or plugins fail

Check Niri version and your GPU drivers. Noctalia plugins can depend on additional programs; the plugin manifests list their needs. This upstream project is archived and has not been live-tested on every Fedora system.

Get your previous configs back

amethystos-uninstall --dry-run
amethystos-uninstall

AmethystOS restores tracked configurations only when they have not been modified. Fedora packages and GNOME are not uninstalled. Read migration details.

Security and attribution

The repository is AI-assisted and not independently audited. The installer may add a third-party repository for archived Noctalia v4 only after explicit consent. Review the source and keep a backup. Gigi's MIT source and separately licensed Noctalia plugins are credited in the project.
