Where the configuration lives

The install places Niri and application configuration in your home directory. Niri uses the KDL format and can reload changes to its configuration. Official Niri documentation ↗

~/.config/niri/Layouts, keybindings, window rules and session startup
~/.config/waybar/Panel modules and CSS styling
~/.config/fuzzel/Application launcher appearance
~/.config/mako/Notification settings
~/.config/alacritty/Default terminal theme

Changing keybindings

Edit ~/.config/niri/keybinds.kdl. The site's reference is generated from the repository's default file, not your personal edits.

In a Niri installation
niri validate

Run the validator after changes; it reports invalid syntax and configuration errors.

Wallpaper

AmethystOS includes an original default wallpaper, Amethyst Light or Amethyst Dark. The installer copies these files whenever they are missing, without overwriting existing files or your saved selection in ~/Pictures/wallpapers/; your own wallpapers take precedence. Fresh installs with an empty wallpaper folder select Amethyst Dark by default.

Open the wallpaper picker in a terminal:

Niri Terminal
~/.local/bin/set-wallpaper
# Or switch directly:
set-wallpaper --light
set-wallpaper --dark

Or copy your own JPEG, PNG or WebP files into ~/Pictures/wallpapers/ and use the same picker.

Amethyst Settings

Use Super + Shift + S or the gear on the Waybar to open the settings menu for network, audio, Bluetooth, GTK/Qt appearance, display information and wallpapers. Changing GTK preferences also changes the appearance preference used by GNOME; previous values are saved for restoration.

Not every app follows system colors. Libadwaita uses the GTK color-scheme setting, Qt6 uses qt6ct, while Electron apps, Flatpaks and third-party programs may have their own theme settings.

Adjusting the bar

Edit ~/.config/waybar/style.css for colors and font sizes. The module configuration is in ~/.config/waybar/config.jsonc and related modules/ files. Restart Waybar after editing:

Niri Terminal
pkill -x waybar
waybar >/dev/null 2>&1 &
Tip: Keep a backup of your modified config. Re-running the installer may ask whether to replace it with the repository defaults.
