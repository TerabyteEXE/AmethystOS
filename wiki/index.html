Get started in a minute

After logging into the Niri session, these shortcuts will get you moving:

Super + EnterOpen Alacritty terminal
Super + SpaceSearch installed applications
Super + WClose the focused window
Super + Shift + TabToggle tabbed columns
Super + H / LMove between columns
Super + OShow workspace overview
Super + Shift + /Open built-in hotkey overlay

What AmethystOS installs

Niri handles the window layout. Waybar displays desktop status. Fuzzel launches apps, Mako handles notifications, swaybg displays wallpapers, and Alacritty is the default terminal.

Its important to note that Fedora keeps managing packages, user accounts, hardware, and updates. AmethystOS on purpose does not replace Fedora's system services or default login manager as I wanted the OS to not skip on security like other distributions which prioritize visual designs over some simple security.

Project transparency

The installer and documentation were created with help from AI. They have of course not received an independent security audit. Use them with the same caution you would use with any third-party Linux scripts or distros you find on the internet.
