Get started in a minute

After logging into the Niri session, these shortcuts will get you moving:

Super + EnterOpen Alacritty terminal
Super + SpaceOpen Fuzzel application launcher
Super + QClose the focused window
Super + H / LMove between columns
Super + OShow workspace overview
Super + Shift + /Open built-in hotkey overlay

What Kuhl OS installs

Niri handles the window layout. Waybar displays desktop status. Fuzzel launches apps, Mako handles notifications, swaybg displays wallpapers, and Alacritty is the default terminal.

Fedora keeps managing packages, user accounts, hardware, and updates. Kuhl OS does not replace Fedora's system services or default login manager.

Project transparency

The desktop files were adapted from New Niri Minimal Dots by Aditya Verma under MIT, with the original notice in LICENSE.upstream. Fedora-specific changes are described in docs/UPSTREAM.md.

The installer and documentation were created with AI assistance. They have not received an independent security audit. Use them with the same care you would use any third-party Linux setup script.
