About the project

AmethystOS

A small, independent desktop project based on Fedora Workstation.

Project

HomeInstallWiki

The idea

AmethystOS brings a coherent keyboard-driven desktop to Fedora with Niri and Noctalia. We prioritize a dependable installer, easy-to-learn shortcuts, and clear documentation instead of hiding Linux behind proprietary tools.

Development

AmethystOS is a personal, AI-assisted project under active development. It is not affiliated with Fedora, Niri, or Noctalia. Read the source and understand the risks before using it.

Looking ahead

Future releases may offer stronger integration and eventually a standalone installer ISO. Today AmethystOS installs on an existing Fedora system.
