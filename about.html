A little about AmethystOS

As you now know, AmethystOS is a preconfigured Niri desktop for Fedora. It brings together a tiling window manager, a simple launcher, a status bar and useful keyboard shortcuts in one neat installable setup. The main inspiration for the project was the desire to make a distro that was actually what I wanted. I have been a long time Debian user and have done a little work in Arch and some other core distributions. The main issue with those distros was the UI and design. Then I discovered Arch and its amazing rices that people had done with Hyprland and other tiling window managers. After installing Omarchy I understood how big a difference a well-configured desktop could make with someones workflow.

Sadly though I would never be able to get what I wanted. I thought for a moment I had found the perfect distro, Omarchy. The fact of the matter is there where a few problems with it and honestly is with all the other Arch + Hyprland alternatives. The AI intagration was over the top for me and the security issues where a little worrying to say the least. Also, as it was based on Arch Linux, it was always going to be updating and I knew that bleeding edge releases where just not for me. Don't get me wrong, Omarchy doesnt really do anything wrong per say it was just not for me as I really needed something with a base like Debain is to Ubuntu or Fedora is to its other spins, those both had stability on its side. So thats why AmethystOS was made.

AmethystOS is a project I created to fill the gap I saw in the distro sea. It is meant to be a stable, well-configured desktop environment based on Fedora and its main strength is the balance between decent security and really strong asthetics(in my humble opinion). AmethystOS is not going to be perfect of course, but perhaps for those few who want that juicy Fedora base but dont want to have to get some unstable constantly breaking Hyprland rice, maybe it would be perfect. I'm not going to act like the project is a 10/10 distro for our modern times. Its just a simple project that I hope you will be able to benifit from. So, thats it. Before you finish reading I just want to say thank you for checking this project out! I hope either if you use it or don't, that you will be benifited in some way by my work. Stay curious! ;)
