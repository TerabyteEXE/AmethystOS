# Third-party components and attribution

AmethystOS is an independent Fedora/Niri desktop configuration using Noctalia v5.
Refer to the upstream Fedora, Niri and Noctalia licenses and notices.
A historical MIT-licensed configuration contributed to earlier revisions; its
copyright and permission notices are retained in
`third_party/gigis-rice/LICENSE`. The bundled Neovim configuration still
includes code derived from that source. A brief acknowledgement appears at
the end of the README.
No upstream desktop theme snapshot is shipped or installed in this version.
