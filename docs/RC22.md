# AmethystOS RC2.2 desktop polish

The default rice is retained. Five **named** workspaces are kept in Niri's config, but Niri can still create dynamic workspaces beyond them. Waybar shows the named workspaces according to their output.

## Desktop scaling
Niri handles each monitor's physical Wayland scale; AmethystOS does not guess monitor DPI or override your output configuration. `amethyst-scale auto` resets additional text scaling, while 100, 115, 125, 150 and 175 percent adjust Waybar, Fuzzel, Mako, Kitty, Alacritty and GTK text scaling on supported systems. On some GTK apps changing GSettings may also affect your GNOME fallback. AmethystOS preserves and restores an original GSettings text multiplier when it was the last writer. A restart of already open terminal windows may be needed.

## Themes
`amethyst-theme dark` and `amethyst-theme light` use bundled palette configurations and the `AmethystDark.png` / `AmethystLight.png` wallpapers. Changes are managed and tracked for safe uninstallation; if you manually edit desktop configs first, the theme command refuses to overwrite those changes. Third-party/Flatpak/Electron app themes remain app-specific.

## Boot integration
The experimental Plymouth splash mentioned in the original RC2.2 build was removed in RC2.5. The current installer does not change Fedora’s boot screen or rebuild initramfs. If you installed that old system-level splash, see `docs/UPGRADING.md` to restore your prior Plymouth theme manually.

## Applications
Steam, OBS Studio, Discord and Flatseal use **Flathub** with a user-scoped remote, added only if selected. Review third-party packages and privileges before accepting. The installer reports failures rather than making them desktop-critical.

## Testing
Run `bash tests/validate.sh`. Native Fedora/Niri validation and actual graphical login, settings actions, per-monitor DPI, remain manual release gates.
