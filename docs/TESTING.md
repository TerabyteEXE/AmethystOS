# Kuhl OS — beta testing

See `RELEASE-CHECKLIST.md` and run `bash tests/validate.sh` on any Linux with bash/Python.
On Fedora with Niri installed, run `python3 scripts/validate_niri.py` and then `niri validate`.
Log into the Niri session and test bar, launcher, settings, monitor scaling, wallpapers, backups, and recovery.
Do not claim a stable OS release until the real desktop session and installer have been checked.
